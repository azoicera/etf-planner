# 投资策略说明

本项目内置策略为“红利ETF长期定投执行纪律模板”，重点不是预测市场，而是帮助投资者用固定规则执行长期计划。

## 资金拆分

默认年度投入资金 X 拆分为：

| 资金池 | 默认比例 | 作用 |
|---|---:|---|
| 基础定投 | 70% | 保证资金持续进入市场，减少现金拖累 |
| 下跌增强 | 20% | 在市场明显下跌时分批加仓 |
| 再平衡 | 10% | 初始保留现金；上涨止盈后与止盈资金组成再平衡池 |

## 月中/月末双定投

基础定投资金分成 24 次投入：

- 每月15日前后：投入一次
- 每月25-28日：投入一次

每次投入金额：

```text
年度总投入 X × 基础定投比例 ÷ 24
```

## 阶段高点 H

阶段高点建议使用：

```text
最近120个交易日最高收盘价
```

每月第一个交易日更新一次。

## 下跌增强加仓

当 ETF 价格相对阶段高点 H 回撤达到以下阈值时，分档使用增强资金：

| 回撤 | 动作 |
|---:|---|
| -10% | 第1档加仓 |
| -15% | 第2档加仓 |
| -20% | 第3档加仓 |
| -25% | 第4档加仓 |
| -30% | 第5档加仓 |

## 上涨止盈

当 ETF 相对整体持仓成本 C 达到：

| 涨幅 | 动作 |
|---:|---|
| +30% | 卖出总仓位10% |
| +40% | 再卖出总仓位10% |
| +50% | 再卖出总仓位10% |

卖出资金进入再平衡现金池。

## 风险提示

- 红利ETF不是保本理财。
- 历史分红和历史收益不代表未来。
- 本策略更适合长期、低频、纪律型投资者。
